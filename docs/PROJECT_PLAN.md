# Entrega AUREO

Implementadas: fundação isolada; migrations de moda; nova identidade e catálogo;
variantes, sacola e checkout de teste; painel proprietário e mídia persistente preparada;
assistente adaptado opcional; testes, build e documentação Ubuntu.

Não habilitadas: vendas reais, Pix, frete real, conta Cloudinary, chamadas reais de IA,
envio de campanhas, políticas comerciais finais e deploy. Essas integrações exigem
credenciais, dados e decisões operacionais da marca. Consulte README e DEPLOYMENT.
